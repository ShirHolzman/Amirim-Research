4. THE CONTROL -- does re-fitting beat 1-parameter recalibration?
==============================================================================
   Fit each recalibrator on TRAINING, apply to EDA. If a content-free
   1-parameter transform matches a 3-parameter psychological re-fit,
   the 're-fitted psychology' is really just over-confidence.

   model (fit on train, scored on EDA) #par   E[log p]      ECE   vs pub
   published CATIE                       0    -0.7046   0.1736  +0.0000
   + temperature (T=2.030)               1    -0.6235   0.0836  +0.0811
   + Platt (2 par)                       2    -0.6193   0.0706  +0.0854
   + isotonic (nonpar)                  np    -0.5988   0.0232  +0.1058
   re-fitted (tau,eps,phi)               3    -0.5975   0.0293  +0.1071

   1-par temperature  +0.0811  = 76% of the re-fit gain
   nonpar isotonic    +0.1058  = 99% of the re-fit gain
   3-par re-fit       +0.1071

   The isotonic row is the decisive comparison, not temperature. Isotonic
   is the BEST POSSIBLE monotone recalibration of p_alt1 -- it has zero
   psychological content and cannot use any information beyond the ordering
   of CATIE's own forecast. So:
   => re-fitting essentially MATCHES nonparametric recalibration. The three
      fitted parameters are buying CALIBRATION, not better psychology:
      almost all of the gain is recoverable by monotonically squashing the
      published model's probabilities. Fitted values should NOT be read as
      revised estimates of exploration/inertia tendencies.

   NOTE E[p] moves the OPPOSITE way (0.6153 -> 0.5953): the fit trades
   mean-probability accuracy for log-score accuracy, which is exactly the
   E[p]/E[log p] dissociation Phase 2 identified.
