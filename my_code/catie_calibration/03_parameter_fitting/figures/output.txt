4. THE CONTROL -- does re-fitting beat 1-parameter recalibration?
==============================================================================
   Fit each recalibrator on TRAINING, apply to EDA. If a content-free
   1-parameter transform matches a 3-parameter psychological re-fit,
   the 're-fitted psychology' is really just over-confidence.

   model (fit on train, scored on EDA) #par   E[log p]      ECE   vs pub     E[p]
   published CATIE                       0    -0.7046   0.1736  +0.0000   0.6153
   + temperature (T=2.030)               1    -0.6235   0.0836  +0.0811   0.5735
   + Platt (2 par)                       2    -0.6193   0.0710  +0.0853   0.5778
   + isotonic (nonpar)                  np    -0.5988   0.0225  +0.1058   0.5937
   re-fitted (tau,eps,phi)               3    -0.5975   0.0293  +0.1071   0.5953
   Every recalibrated row loses E[p] relative to the published model. The
   algebra behind that: for a LINEAR shrinkage p -> 0.5 + a(p - 0.5),
   dE[p] = (a - 1)(E[p] - 0.5), which is < 0 whenever a < 1 and E[p] > 0.5.
   That identity is exact only for a linear shrinkage of p. None of the rows
   above is one: temperature is linear in the LOGIT, isotonic is an arbitrary
   monotone map, and the re-fit is a different model rather than a transform
   of this one. So the algebra is the mechanism these numbers are CONSISTENT
   WITH, not a derivation of them -- the losses themselves are measured.

   1-par temperature  +0.0811  = 76% of the re-fit gain
   nonpar isotonic    +0.1058  = 99% of the re-fit gain
   3-par re-fit       +0.1071

   isotonic / re-fit gain ratio on EDA = 0.988, subject-cluster bootstrap 95% CI [0.968, 1.009] (2000 resamples, n = 496 subjects)
   M2 re-fit - isotonic, paired subject test on EDA: +0.0013 [-0.0009, +0.0036]  t = 1.09  p = 0.28 n.s.

   The isotonic row is the decisive comparison, not temperature. Isotonic is
   the best monotone recalibration of p_alt1 that Training can fit -- it has
   zero psychological content and cannot use any information beyond the
   ordering of CATIE's own forecast. So:
   => re-fitting essentially MATCHES nonparametric recalibration. The three
      fitted parameters are buying CALIBRATION, not better psychology:
      almost all of the gain is recoverable by monotonically squashing the
      published model's probabilities. Fitted values should NOT be read as
      revised estimates of exploration/inertia tendencies.

   NOTE E[p] moves the OPPOSITE way (0.6153 -> 0.5953): the fit trades
   mean-probability accuracy for log-score accuracy, which is exactly the
   E[p]/E[log p] dissociation Phase 2 identified.

   model                            #par  E[log p] EDA    vs M0  E[p] EDA    vs M0
   M0 published params                 0       -0.7046  +0.0000    0.6153  +0.0000
   M1 + temperature (control)          1       -0.6235  +0.0811    0.5735  -0.0418
   M2 re-fitted (tau,eps,phi)          3       -0.5975  +0.1071    0.5953  -0.0200
   M3 + run-length phi (>=4)           5       -0.5915  +0.1131    0.6014  -0.0139
   Every rung loses E[p] relative to M0. The algebra of a LINEAR shrinkage
   p -> 0.5 + a(p - 0.5) is dE[p] = (a - 1)(E[p] - 0.5), negative whenever
   a < 1 and E[p] > 0.5, and that identity is exact for a linear shrinkage
   only. M1 is linear in the logit; M2 and M3 are different models, not
   transforms of M0. Every rung is nonetheless a net squash toward 0.5, so
   the pattern is CONSISTENT WITH that algebra rather than implied by it.

   For scale, the paper's CATIE-vs-best-QL gap is -0.109.
   Total gain here (M0 -> M3): +0.1131 = 104% of that gap.
