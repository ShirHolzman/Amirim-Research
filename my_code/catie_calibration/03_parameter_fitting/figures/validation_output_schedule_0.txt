2. WHICH CONVENTIONS REPRODUCE THE PAPER? (k-weighting x trial 1)
==============================================================================
   Two choices affect the reported averages and NEITHER is documented:
     k-weighting : 'per_trial'        -- hetro.m's own commented line 26
                   'shipped_time_avg' -- what hetro.m:25 actually runs
     trial 1     : kept or dropped -- it is fixed at p=0.5 by the model,
                   so including it drags both metrics toward the middle
   Both are determined EMPIRICALLY, by which combination reproduces the
   paper's own per-schedule values. A correct reproduction should land at
   the 3-decimal rounding floor (5e-4) with MIXED-SIGN residuals; a
   same-signed residual on every schedule is a systematic error.

   k-weighting       trial 1     max|dE[p]|  max|dE[logp]|   logp signs
   per_trial         kept            0.0002         0.0004        1+/0-
   per_trial         dropped         0.0019         0.0015        1+/0-
   shipped_time_avg  kept            0.0002         0.0034        1+/0-
   shipped_time_avg  dropped         0.0020         0.0046        1+/0-

   => best: weighting='per_trial', trial 1 KEPT (worst error 0.0004)
   Sections 3-4 use those conventions.
   NOTE Phases 1-3 report their own headline numbers with trial 1 DROPPED
   (it carries no model information). That is a reporting choice and is
   unrelated to reproducing the paper's absolute values, which is what
   this script does.
