2. IS TRIAL 1 INCLUDED IN THE PAPER'S AVERAGE?
==============================================================================
   Trial 1 is fixed at p=0.5 by the reference implementation, so including
   it shifts both metrics. We do not know the paper's choice a priori --
   we determine it empirically, by which one reproduces the reported values.

   drop trial 1   mean|dE[p]| = 0.0013   mean|dE[log p]| = 0.0046
   keep trial 1   mean|dE[p]| = 0.0006   mean|dE[log p]| = 0.0049

   Using drop_first=True below (the convention used throughout Phases 1-3).

4. VERDICT
==============================================================================
   published port vs paper: max |dE[p]| = 0.0018, max |dE[log p]| = 0.0055  (tolerance 0.002)
   E[p]     reproduced on all 3 schedules : YES
   E[log p] reproduced on all 3 schedules : NO
   NOTE: every E[log p] residual has the SAME sign (mean +0.0046).
   A same-signed residual on every schedule is a SYSTEMATIC difference, not
   rounding noise. E[p] matching while E[log p] does not means the port puts
   the same average mass on the chosen action but spreads it slightly
   differently across trials -- log-score punishes the low tail, E[p] does not.

   Subject-weighted pooled over the 3 eda schedules:
      reported (paper)   E[p] = 0.6008   E[log p] = -0.7190
      published port     E[p] = 0.6021   E[log p] = -0.7143
      corrected port     E[p] = 0.6155   E[log p] = -0.6996
      re-fitted (held out)   E[p] = 0.6022   E[log p] = -0.5917

   READ THIS BEFORE QUOTING ANY BASELINE E[p]:
   The paper's numbers describe the PUBLISHED (buggy) model. Any comparison
   of a re-fitted or recalibrated variant against the paper must state which
   baseline it uses, because published and corrected differ materially.
