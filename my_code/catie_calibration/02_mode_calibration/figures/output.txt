5. HARD vs SOFT MODE ATTRIBUTION
==============================================================================
   OLD (planning-phase) method: hard argmax over mass toward 'choosing alt1'.
   Forced to equal c_prev exactly for the inertia regime (its contribution is
   phi*c_prev, identically 0 when c_prev=0) -- not an empirical finding.

   P(c_prev=1 | hard_argmax):
                mean   count
hard_argmax                 
contingent_avg   0.0   68872
exploration      0.0   19296
heuristic        0.0    3380
inertia          1.0  158328

   NEW method: Bayesian responsibility posterior. Genuinely NOT forced to
   be deterministic in c_prev (see responsibility.py) -- confirmed below.

   P(c_prev=1 | soft_argmax):
                    mean   count
soft_argmax                     
contingent_avg  0.299182   53322
exploration     0.890224   22546
heuristic       0.779683    7698
inertia         0.699309  166310

   BUT: the responsibility posterior is computed FROM the observed choice
   y(t) (resp_r(t) uses y(t) to pick contribution_r(t) vs weight_r(t)-
   contribution_r(t)) -- so soft_argmax is RETROSPECTIVE, not a forecasting
   partition, and must not be scored the way c_prev/hard_argmax are.
   Direct proof: within every single (c_prev, soft_argmax) cell, does
   chose_biased come out exactly 0 or 1 (i.e. does the label recover y(t)
   outright)?

                       mean   count
c_prev soft_argmax                 
0.0    contingent_avg   1.0   37369
       exploration      1.0    2475
       heuristic        1.0    1696
       inertia          0.0   50008
1.0    contingent_avg   0.0   15953
       exploration      0.0   20071
       heuristic        0.0    6002
       inertia          1.0  116302

   every cell mean in {0, 1}: True  -- confirmed circular, as expected

   soft_argmax's legitimate use is therefore RETROSPECTIVE ERROR ATTRIBUTION:
   'of the choices CATIE got most wrong, which regime's implicit confidence
   was responsible' -- see section 7. It cannot be used as-is to improve a
   real-time forecast, and its R^2-of-gap-explained is not reported, because
   it would not mean what a reader would assume it means.
